# Código do Terra3d

Esta pasta contém o projeto Maven do planeta 3D em JavaFX.

Com JDK 17 e Maven instalados, execute nesta pasta:

```bash
mvn clean compile javafx:run
```

Arraste o mouse para girar o planeta e use a roda para o zoom. Consulte o [README principal](../README.md) para funcionalidades, estrutura e próximos passos. A licença do código próprio está em [LICENSE](../LICENSE).
